Question 1 : What is the difference between == and === operators? + -
Answer
  • == (Loose Equality / Abstract Equality): This operator compares two values for equality after converting both values to a common type (this process is called Type Coercion). For example, 5 == "5" will return true because JavaScript converts the string "5" into a number before comparing.
  • === (Strict Equality): This operator compares both the value and the data type without doing any type conversion. If the types are different, it immediately returns false. Therefore, 5 === "5" returns false because a number type is not equal to a string type.
Question 2: What is Event.preventDefault() and why do we use it in forms? + -
Answer
Event.preventDefault() is a built-in JavaScript method that stops the default action belonging to an event from happening.
  • Default Behavior: When you click a "Submit" button inside an HTML form, the browser automatically tries to refresh the entire webpage and send the data to the URL specified in the form action.
  • Why we use it: In modern web apps, we want to intercept this process so we can validate the user input (e.g., checking if the email format is correct) before sending it to a database using APIs. Calling e.preventDefault() freezes the browser from refreshing, allowing our custom JavaScript validation logic to run.
Question 3: What is the difference between element.style.cssText and element.style.property? + -
Answer:
Both are used to modify the inline CSS styles of an HTML element via JavaScript, but they handle multiple properties differently:
  • element.style.property (e.g., .style.color = "red"): Modifies or adds one specific CSS property at a time. It keeps any other existing inline styles completely safe and untouched.
  • element.style.cssText (e.g., .style.cssText = "color: red; display: block;"): Allows you to apply a whole raw string of CSS rules all at once using semicolons.

Warning: cssText is destructive. It completely overwrites and deletes all previous inline styles on that element, replacing them entirely with the new string.

Question 4: How does setInterval() work and how do you stop it? + -
Answer:
setInterval() is a timing function used to repeatedly execute a specific piece of code or function at fixed time intervals (measured in milliseconds). For example, updating an automatic image carousel every 10 seconds.
  • How it works: When you declare setInterval(myFunction, 10000), it returns a unique numeric identification code called an Interval ID.
  • How to stop it: To halt the timer permanently, you must capture that specific Interval ID into a variable and pass it inside JavaScript's built-in clearInterval() function.
