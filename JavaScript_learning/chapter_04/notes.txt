Bhai, tumne ekdum aag lagane wala sawaal pucha hai! Aur yeh sawaal har us insaan ke dimaag me aata hai jo C++, Java, ya Python seekh kar JavaScript me aata hai.

Iska seedha jawaab hai: **JavaScript me `class` hoti hai, lekin woh asli `class` nahi hoti!** JavaScript ke parde ke peeche ka sach yeh hai ki JS me asli OOPs (jaise Java me hota hai) nahi hota. JS kaam karta hai **Prototypes** par. Chalo is kahani ko ekdum mazedaar tarike se samajhte hain.

---

### Kahani: JavaScript me `class` kaise aayi?

JavaScript banayi gayi thi sirf 10 din me (1995 me). Us waqt iske creator (Brendan Eich) ne isko baki languages se alag rakha. Unhone kaha, *"Hum class-wlass ka jhanjhat nahi rakhenge, hum sab kuch Objects se hi chalayenge."* Isko bolte hain **Prototype-based OOPs**.

Lekin 2015 tak aate-aate, Java aur C++ ke developers jab JS me code likhne aaye, toh unka dimaag ghum gaya. Unhe bina `class` ke maza hi nahi aa raha tha.

Toh JavaScript walo ne unhe khush karne ke liye 2015 (ES6) me **`class` keyword** de diya. Lekin woh sirf ek dhoka hai! Use programming ki duniya me **Syntactic Sugar** kehte hain.

> **Syntactic Sugar kya hai?** > Kisi cheez ko andar se badle bina, bahar se bas dekhne me sundar aur aasan bana dena.

---

### Parde Ke Peeche Ka Sach (Difference)

Jab aap JS me yeh likhte ho:

```javascript
class Student {
    constructor(name) {
        this.name = name;
    }
}

```

Toh JavaScript ka compiler parde ke peeche (internally) usko automatic isme badal deta hai:

```javascript
function Student(name) {
    this.name = name;
}

```

JavaScript me koi asli `class` ka concept computer ki memory me nahi banta. Parde ke peeche aaj bhi sirf **Functions aur Objects** hi ek dusre se judte hain (jise hum Prototype Chain kehte hain).

---

### Toh kya JS me Class use karna galat hai?

**Bilkul nahi!** Aaj ke time par 95% developers `class` syntax ka hi use karte hain kyunki:

1. Yeh dekhne me saaf-suthra lagta hai.
2. Isko padhna aur samajhna aasan hota hai.
3. Agar aap kisi aur language se aaye ho, toh aapko apna-apan lagta hai.

### Summary

JS me OOPs hota hai, lekin uska tarika alag hai (Object se Object judta hai, na ki Class se Object banta hai). `class` keyword JS me sirf developers ke aaram ke liye diya gaya hai, background me computer use ek normal function ki tarah hi chalata hai!
